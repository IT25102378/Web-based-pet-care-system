Notes
-----
An administrator account cannot be created through the registration form. The
backend rejects role=Admin on registration, so the administrator above is the
only one and it is created by the seeder.

A newly registered account is PendingApproval and cannot sign in until an
administrator approves it. There is no email step.

Before demonstrating, clear the browser site data for http://localhost:3000
once. The application used to run in mock mode by default and stored records in
the browser instead of the database; a browser that was used back then still
holds that old data and will show accounts that are not in SQL Server.
